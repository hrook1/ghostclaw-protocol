02 / The payment path

x402 runs. Amount stays private.

GhostClaw adds a private payment proof to the x402 request. The merchant verifies settlement before it releases the service.

01 / REQUEST

Quote

The merchant returns an x402 payment requirement.

Merchant stays public
02 / LOCAL

Prove

The payer creates the payment proof on its machine.

Keys and notes stay local
03 / BASE

Settle

The Base contract verifies the proof and updates public commitments.

Amount stays unreadable
04 / SERVICE

Continue

The merchant confirms settlement and releases the resource.

x402 response resumes
03 / Performance

Local proving reduces latency.
